Capabilities

Power Cut & UPS Detection

Monitors AC power state via WMI and psutil. Triggers immediate git checkpoints when power drops before battery runs dry.

Submarine Cable Routing

Detects SMW4/AAE-1 cable congestion and switches npm and pip to high-speed Asian mirror networks automatically.

Pakistani ISP Profiling

Identifies your provider (PTCL, StormFiber, Nayatel, Jazz, Zong) and compensates for known evening routing quirks.

Adaptive Survival Engine

Dynamically switches between NORMAL, NETWORK DEGRADED, POWER UNSTABLE, and CRITICAL operating policies.

Roman Urdu Error Translations

Translates ECONNREFUSED, timeouts, and install errors into actionable plain language so you know when the issue is network-side.

Local & Zero-Overhead

Operates entirely locally with cached state evaluation in under 5ms, with zero impact on tool execution speeds.

About jugaad-code

Pakistani developers frequently work through load-shedding schedules, sudden power disruptions, and fluctuating international routing due to submarine cable maintenance in the Arabian Sea.

jugaad-code was built as a pragmatic resilience layer for Claude Code. It runs silently in the background, automatically safeguarding unsaved work during power outages, rerouting package registries when international gateways bottleneck, and translating obscure infrastructure errors into clear, context-aware advice.

Designed for Pakistan, with an architecture that scales to any developer working under challenging infrastructure conditions worldwide.
