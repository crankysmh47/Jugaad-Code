Documentation & Technical Guide

Everything you need to configure, extend, and run jugaad-code with Claude Code on Windows, macOS, and Linux.

Installation

Run the one-command installer in your shell. It downloads the resilience scripts to ~/.jugaad-code/, copies slash commands to ~/.claude/commands/, and merges hook configurations into ~/.claude/settings.json:

Slash Commands Reference

/doctor Full Health Check

Runs a complete diagnostic scan of your developer environment:

  • Power Status: Queries WMI (Windows) or psutil (Linux/macOS) for AC connection, battery %, and remaining runtime.
  • Internet Diagnostics: Tests DNS latency, TCP handshake, and TTFB against GitHub, NPM registry, PyPI, and Anthropic API.
  • ISP Fingerprinting: Detects provider (PTCL, StormFiber, Nayatel, Jazz, Zong) and flags known routing issues.
  • Root-Cause Analysis: Categorizes issues into LOCAL_NETWORK, SUBMARINE_CABLE, ISP_ROUTING, or ALL_OK.
/pk on | /pk off | /pk status Pakistan Mode Toggle

Controls the background guardian daemon, mirror routing, and terminal theme:

  • /pk on: Starts the background guardian daemon, switches npm to registry.npmmirror.com, switches pip to pypi.tuna.tsinghua.edu.cn, and enables the Pakistan Green theme.
  • /pk off: Gracefully stops the guardian process, restores default npm/pip registries, and reverts your original theme.
  • /pk status: Reports current guardian PID, state cache freshness, active theme, and mirror settings.
/checkpoint Emergency Git Commit

Scans the current repository for modified/untracked files and creates an atomic git checkpoint commit (chore: [PK-checkpoint] manual @ ...) so work is never lost.

Adaptive Survival Mode Engine

jugaad-code continuously updates a lightweight local state cache (~/.jugaad-code/state.json) across 4 operational states:

NORMAL

Stable AC power and low international latency. No restrictions or rerouting applied.

NETWORK DEGRADED

High international latency (>3000ms) or cable disruption. Automatically routes installs through Asian mirrors and prefers local package cache.

POWER UNSTABLE

AC power loss detected. Workspace auto-checkpoint commits on state change, and warnings appear before long-running build tasks.

CRITICAL

Battery under 15% during network instability. Restricts non-essential operations, triggers immediate commits, and protects unsaved edits.

Hook Architecture

Claude Code executes cross-platform Python hooks before and after tool calls:

  • Pre-Tool Hook (scripts/pre_tool_hook.py): Reads state cache in <5ms. Warns on degraded infrastructure and auto-commits when battery is low.
  • Post-Tool Hook (scripts/post_tool_hook.py): Intercepts failures (ECONNREFUSED, timeouts) and translates them to human Roman Urdu explanations.
  • Statusline (scripts/statusline.py): Dynamically injects the current survival state and rotating desi humor into Claude Code’s status bar.
